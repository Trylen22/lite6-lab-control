How detection works

Color detection is a sequence of small, inspectable decisions.

  1. Capture a frame

    Read a fresh color image from the OAK camera.

  2. Select a color range

    Convert BGR to HSV, then keep matching pixels.

  3. Find useful shapes

    Clean the mask and reject small or narrow regions.

  4. Describe what it found

    Report its box and pixel measurements. Pickup turns those into arm millimeters using the tabletop calibration.

    Lessons

    Each chapter has an experiment and a checkpoint before the next.

    1. Observe and detect

      Trace a frame from the OAK camera through color thresholds or local YOLO, and read the arm's status without moving it.

      Compare plain, mask and overlay views. Explain a centroid, a confidence score and a false positive. labdeck/color.py

    2. Measure and calibrate

      Relate pixels to arm millimeters with known reference points, and measure the error on points the fit never saw.

      Checkpoint: measurements with documented uncertainty.

    3. Teach controlled motion

      Confirm the E-stop, tool, payload, clear workspace and speed limits before any movement.

      Checkpoint: supervised, slow motion with stops tested.

    4. Pick, place and explain

      Build a state machine you can inspect: find, check, approach, pick, carry, release, verify.

      Checkpoint: repeated supervised trials with measured outcomes.
