09 · pipeline.txt

Color detection is a sequence of small, inspectable decisions.

  1. capture a frame

    Read a fresh color image from the OAK camera.

  2. Select a color range

    Convert BGR to HSV, then keep matching pixels.

  3. Find useful shapes

    Clean the mask and reject small or narrow regions.

  4. describe the candidate

    Show its bounding box and image measurements.

Measurements are in image pixels. The pickup controller applies the validated tabletop profile.

learning//path_

Each chapter has a clear experiment and a checkpoint.

chapter 01 · current

Observe & detect

Trace a frame from the OAK camera through OpenCV color thresholds or local YOLO. Read robot status without sending movement commands.

  • Compare raw, threshold mask, and annotated images.
  • Explain a centroid, a confidence score, and a false positive.
  • Verify stale frames never appear as fresh detections.
labdeck/color.py · yolo.py · robot.py
chapter 02 · measure

Measure & calibrate

Confirm the camera mounting and tool geometry. Measure pixel, camera, and robot coordinate frames with known reference points.

  • Record camera intrinsics and the camera-to-robot transform.
  • Measure error on reference points excluded from calibration.
Checkpoint: validated measurements, documented uncertainty.
chapter 03 · motion

Teach controlled motion

Verify mounting, emergency stop, tool/payload, clear workspace, speed limits, and explicit operator authorization before introducing movement.

Checkpoint: supervised motion validation.
chapter 04 · pick

Pick, place & explain

An inspectable state machine: acquire → validate → approach → pick → transfer → release → verify.

Checkpoint: repeated supervised trials with measured outcomes.

session boundaries

Frames and detections are processed locally. The dashboard serves only this laptop. Page loads never move the arm; only the demo tabs and the explicit buttons request motion.

Color thresholds describe appearance. YOLO predictions describe learned classes and never trigger motion.
